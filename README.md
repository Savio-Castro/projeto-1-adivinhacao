# Jogo de Adivinhação - O Cofre (C#)

O que foi implementado:
- `Console.WriteLine` e `Console.ReadLine` para exibir mensagens e ler o que o usuário digita.
- `switch` para escolher os níveis.
- `while` para laços de repetição.
- `if`, `else if` e `else` para testar possibilidades.
- `&&` e `||` (operadores lógicos) e `>` e `<` (operadores relacionais).
- `Convert.To...` para converter variáveis de string para outros tipos.
